# 88-EAN · FinOps y Optimización de Costos Cloud

Universidad Ean · Educación Continua · Docente: Jawy Andrés Romero Pinto

Material del curso **FinOps y Optimización de Costos Cloud** (Microsoft Azure).
Curso práctico de 5 sesiones sobre cómo llevar responsabilidad financiera a la
nube: ver el gasto, asignarlo, presupuestarlo, optimizarlo y gobernarlo.

## Índice de sesiones

| # | Fecha | Carpeta | Sesión | Estado |

| 03 | MI 2 sep | `03-presupuestos-alertas/` | Presupuestos, alertas, anomalías y forecasting | ⏳ |

El curso recorre el **FinOps Framework**: Informar (S1–S2) → Optimizar (S3–S4) →
Operar (S5).

## Plataforma y cuentas

Los laboratorios usan **Microsoft Azure** con cuentas **Azure for Students**
($100 de crédito, 12 meses, sin tarjeta). El diseño respeta los límites de la
cuenta de estudiante: se usa la **calculadora de precios** y recursos mínimos, con
limpieza obligatoria para no consumir el crédito. Las partes que una cuenta de
estudiante no permite (p. ej. comprar reservas) se trabajan con la calculadora y
datos de ejemplo.
