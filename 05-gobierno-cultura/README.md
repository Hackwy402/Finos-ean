# Sesión 5 · Gobierno con Azure Policy, cultura FinOps y KPIs

Sesión de **cierre** del curso (fase **Operar** del FinOps Framework): hacer
sostenible todo lo aprendido. Que el ahorro no se pierda — con políticas que
previenen el desperdicio, cultura de costos y métricas.

## Objetivos

- Entender el **gobierno** como prevención (reglas), no persecución.
- Usar **Azure Policy** (efectos Deny / Audit / Modify) para exigir buenas prácticas.
- Conocer la **cultura FinOps** (los 6 principios de la FinOps Foundation).
- Ubicarse en el **modelo de madurez** (gatear → caminar → correr).
- Definir **KPIs** que prueben que la práctica funciona (incl. unit economics).

## Laboratorio

Ver [`guia-lab.md`](guia-lab.md). Tres partes (1 hora): asignar una política de
etiqueta obligatoria (Deny/Audit) y comprobar que actúa, definir 3 KPIs con su
fuente, y ubicar a la organización en el modelo de madurez con un plan de 3 acciones.

## Multi-nube y herramientas

Equivalencias Azure ↔ AWS (Azure Policy ↔ Service Control Policies, Management
Groups ↔ Organizations, Blueprints/Landing Zones ↔ Control Tower) con iconos
oficiales, esquema anotado de la pantalla de Policy, y el mapa del curso completo
sobre las tres fases del framework.

Con esta sesión el curso queda completo: **Informar (S1–S2) → Optimizar (S3–S4) →
Operar (S5)**. FinOps no es gastar menos: es maximizar el valor de cada peso.
